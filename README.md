# Emotion Detection & Learning Support Engine

An AI-powered educational support system that detects students' emotions from text and provides personalized learning guidance using Deep Learning and Large Language Models.

## 📌 Project Overview

This project analyzes a student's learning-related text to identify emotional states and generate supportive responses. It combines deep learning models with AI-generated guidance to create a personalized learning experience.

## 🚀 Features

- Emotion Detection from student text
- Text preprocessing and cleaning
- Keyword-based emotion enhancement
- BiLSTM-based emotion classification
- BERT-based emotion classification
- Mixed emotion detection
- Personalized learning support
- AI-ready guidance engine
- CSV logging of predictions
- Session history tracking

## 🛠️ Tech Stack

- Python
- TensorFlow / Keras
- PyTorch
- Hugging Face Transformers
- Pandas
- NumPy
- Scikit-learn
- Kaggle Notebooks
